AI agents

Kedge

A supervisor for unattended coding agents. It runs an agent to fix failing dependency PRs and checks each step for cheating, like deleted tests or false "all tests pass" claims. When the agent drifts, Kedge rolls back and retries.

Placed 14th of 205 at neatHack 2026. Two startups contacted me about using it.

My part: the evaluation harness (sabotage modes and the 10-PR test set), the CI log context the agent reads, and CI result reporting. Built with one teammate.

Analyses every Premier League club each week and gives the likeliest scorelines and results. It scrapes match data, rates each club, adjusts for lineups and combines a Poisson model with CatBoost.

Runs weekly. Its insights go to players inside GafferScore.
